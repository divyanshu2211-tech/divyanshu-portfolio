# Divyanshu Sagar Portfolio

Responsive portfolio inspired by the supplied reference image, using a fixed left sidebar, charcoal background, warm beige accents, and your supplied profile portrait.

## Run locally
1. Extract the ZIP.
2. Open the `divyanshu_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use VS Code Live Server.
4. Contact email is set to `divyanshusagar27@gmail.com`.
5. Replace the placeholder GitHub and LinkedIn profile URLs with your real URLs.

Files: `index.html`, `style.css`, `script.js`, `assets/profile.jpeg`.
The contact form opens the visitor's default email app; it is not server-backed.
